Part 1

What is minGPT & Why

A GPT meant to be read and hacked, not just run

The Philosophy

🤏

Small

The whole Transformer is ~300 lines of plain PyTorch

🧼

Clean

No clever tricks; readable names, faithful to the paper

🔍

Interpretable

Every tensor shape is commented and easy to trace

🎓

Educational

Built to teach how GPT actually works under the hood

Karpathy's own summary: "All that's going on is that a sequence of indices feeds into a Transformer, and a probability distribution over the next index in the sequence comes out." minGPT favours readability over speed.

A Library, Not a Script — Three Files

mingpt/ model.py # GPT, Block, CausalSelfAttention, NewGELU trainer.py # generic, model-agnostic training loop bpe.py # refactored byte-pair encoder (GPT-2 BPE) utils.py # CfgNode config object + helpers projects/ adder/ # teach a Transformer to add numbers chargpt/ # character-level language model demo.ipynb # sort integers with a tiny GPT generate.ipynb # load pretrained GPT-2 and sample

The key difference from the lecture nanoGPT: minGPT is structured as a reusable library. You import the model and trainer and wire them to your own dataset — the same code trains an adder, a char-LM, or a sorter.

Part 2

CausalSelfAttention

All heads, batched, in a single tidy module

The Projections & the Mask

class CausalSelfAttention(nn.Module):
    """ A vanilla multi-head masked self-attention layer with a
        projection at the end. """

    def __init__(self, config):
        super().__init__()
        assert config.n_embd % config.n_head == 0
        # key, query, value projections for all heads, but in a batch
        self.c_attn = nn.Linear(config.n_embd, 3 * config.n_embd)
        # output projection
        self.c_proj = nn.Linear(config.n_embd, config.n_embd)
        # regularization
        self.attn_dropout = nn.Dropout(config.attn_pdrop)
        self.resid_dropout = nn.Dropout(config.resid_pdrop)
        # causal mask to ensure attention is only applied to the left
        self.register_buffer("bias", torch.tril(torch.ones(config.block_size, config.block_size))
                                     .view(1, 1, config.block_size, config.block_size))
        self.n_head = config.n_head
        self.n_embd = config.n_embd

One combined Linear. c_attn maps n_embd → 3·n_embd so q, k and v for every head are produced in a single matmul, then split apart. register_buffer("bias", …) stores the lower-triangular causal mask as non-trainable state (shape 1×1×T×T ready to broadcast over batch and heads).

The Forward Pass

def forward(self, x):
    B, T, C = x.size() # batch, sequence length, embedding dim (n_embd)

    # calculate query, key, values for all heads in batch and move head forward to be the batch dim
    q, k ,v  = self.c_attn(x).split(self.n_embd, dim=2)
    k = k.view(B, T, self.n_head, C // self.n_head).transpose(1, 2) # (B, nh, T, hs)
    q = q.view(B, T, self.n_head, C // self.n_head).transpose(1, 2) # (B, nh, T, hs)
    v = v.view(B, T, self.n_head, C // self.n_head).transpose(1, 2) # (B, nh, T, hs)

    # causal self-attention; Self-attend: (B, nh, T, hs) x (B, nh, hs, T) -> (B, nh, T, T)
    att = (q @ k.transpose(-2, -1)) * (1.0 / math.sqrt(k.size(-1)))
    att = att.masked_fill(self.bias[:,:,:T,:T] == 0, float('-inf'))
    att = F.softmax(att, dim=-1)
    att = self.attn_dropout(att)
    y = att @ v # (B, nh, T, T) x (B, nh, T, hs) -> (B, nh, T, hs)
    y = y.transpose(1, 2).contiguous().view(B, T, C) # re-assemble all head outputs side by side

    # output projection
    y = self.resid_dropout(self.c_proj(y))
    return y

Reshape to (B, nh, T, hs) puts the head axis next to the batch axis, so a single batched matmul does attention for all heads at once. Scale by 1/√hs, apply the causal masked_fill (future → -∞), softmax, then aggregate values and re-assemble heads side by side before the output projection.

Part 3

The Block & GPT Module

Stacking attention + MLP into a full language model

Block — Pre-LayerNorm Attention + MLP

class Block(nn.Module):
    """ an unassuming Transformer block """

    def __init__(self, config):
        super().__init__()
        self.ln_1 = nn.LayerNorm(config.n_embd)
        self.attn = CausalSelfAttention(config)
        self.ln_2 = nn.LayerNorm(config.n_embd)
        self.mlp = nn.ModuleDict(dict(
            c_fc    = nn.Linear(config.n_embd, 4 * config.n_embd),
            c_proj  = nn.Linear(4 * config.n_embd, config.n_embd),
            act     = NewGELU(),
            dropout = nn.Dropout(config.resid_pdrop),
        ))
        m = self.mlp
        self.mlpf = lambda x: m.dropout(m.c_proj(m.act(m.c_fc(x)))) # MLP forward

    def forward(self, x):
        x = x + self.attn(self.ln_1(x))
        x = x + self.mlpf(self.ln_2(x))
        return x

Pre-norm residuals: LayerNorm is applied before each sub-layer, and the output is added back (x = x + …). The MLP expands 4× (c_fc), applies NewGELU, then projects back down (c_proj) — defined inline as mlpf for a tidy single-expression forward.

GPT — Assembling the Module

self.transformer = nn.ModuleDict(dict(
    wte  = nn.Embedding(config.vocab_size, config.n_embd),
    wpe  = nn.Embedding(config.block_size, config.n_embd),
    drop = nn.Dropout(config.embd_pdrop),
    h    = nn.ModuleList([Block(config) for _ in range(config.n_layer)]),
    ln_f = nn.LayerNorm(config.n_embd),
))
self.lm_head = nn.Linear(config.n_embd, config.vocab_size, bias=False)

# init all weights, and apply a special scaled init to the residual projections
self.apply(self._init_weights)
for pn, p in self.named_parameters():
    if pn.endswith('c_proj.weight'):
        torch.nn.init.normal_(p, mean=0.0, std=0.02/math.sqrt(2 * config.n_layer))

A ModuleDict named after GPT-2: token embeddings wte + positional embeddings wpe → embedding dropout → n_layer Blocks in h → final norm ln_f → the lm_head producing logits over the vocabulary.

Weight Init — The Special Scaled Init

def _init_weights(self, module):
    if isinstance(module, nn.Linear):
        torch.nn.init.normal_(module.weight, mean=0.0, std=0.02)
        if module.bias is not None:
            torch.nn.init.zeros_(module.bias)
    elif isinstance(module, nn.Embedding):
        torch.nn.init.normal_(module.weight, mean=0.0, std=0.02)
    elif isinstance(module, nn.LayerNorm):
        torch.nn.init.zeros_(module.bias)
        torch.nn.init.ones_(module.weight)

Standard init is N(0, 0.02) for Linear and Embedding weights, following GPT-2.

The scaled residual init (previous slide) shrinks every c_proj.weight by 1/√(2·n_layer). Because each layer adds two residual branches, this keeps the variance of the residual stream from growing as the network gets deeper — a per-GPT-2-paper trick that matters a lot for stable deep training.

Part 4

Configuration & Model Zoo

One config system, six named models, and GPT-2 weight surgery

The CfgNode Config System

@staticmethod
def get_default_config():
    C = CN()
    # either model_type or (n_layer, n_head, n_embd) must be given
    C.model_type = 'gpt'
    C.n_layer = None
    C.n_head  = None
    C.n_embd  = None
    # these options must be filled in externally
    C.vocab_size = None
    C.block_size = None
    # dropout hyperparameters
    C.embd_pdrop  = 0.1
    C.resid_pdrop = 0.1
    C.attn_pdrop  = 0.1
    return C

CfgNode (CN) is a tiny attribute-dict config object (in utils.py) shared by the model and the trainer. It supports defaults, nesting, and command-line overrides — giving the library a single, consistent way to configure everything without external dependencies.

from_pretrained() — Loading GPT-2

@classmethod
def from_pretrained(cls, model_type):
    """ Initialize a pretrained GPT model by copying over the weights
        from a huggingface/transformers checkpoint. """
    from transformers import GPT2LMHeadModel
    model = GPT(config)                     # our from-scratch minGPT
    model_hf = GPT2LMHeadModel.from_pretrained(model_type)

    # the openai checkpoints use a "Conv1D" module, but we only want a
    # vanilla nn.Linear. this means we have to transpose these weights.
    transposed = ['attn.c_attn.weight', 'attn.c_proj.weight',
                  'mlp.c_fc.weight', 'mlp.c_proj.weight']
    for k in keys:
        if any(k.endswith(w) for w in transposed):
            assert sd_hf[k].shape[::-1] == sd[k].shape
            with torch.no_grad():
                sd[k].copy_(sd_hf[k].t())   # transpose Conv1D → Linear
        else:
            assert sd_hf[k].shape == sd[k].shape
            with torch.no_grad():
                sd[k].copy_(sd_hf[k])

The weight surgery: OpenAI's GPT-2 stores attention/MLP weights in a Conv1D layout (transposed relative to nn.Linear). minGPT copies HuggingFace's state dict in, transposing exactly those four weight tensors — turning the official 124M–1.5B GPT-2 checkpoints into a runnable minGPT.

configure_optimizers — Selective Weight Decay

# separate out all parameters to those that will and won't experience decay
decay = set()
no_decay = set()
whitelist_weight_modules = (torch.nn.Linear, )
blacklist_weight_modules = (torch.nn.LayerNorm, torch.nn.Embedding)
for mn, m in self.named_modules():
    for pn, p in m.named_parameters():
        fpn = '%s.%s' % (mn, pn) if mn else pn
        if pn.endswith('bias'):
            no_decay.add(fpn)                              # biases: no decay
        elif pn.endswith('weight') and isinstance(m, whitelist_weight_modules):
            decay.add(fpn)                                 # Linear weights: decay
        elif pn.endswith('weight') and isinstance(m, blacklist_weight_modules):
            no_decay.add(fpn)                              # LN/Embedding: no decay

optim_groups = [
    {"params": [...decay...],    "weight_decay": train_config.weight_decay},
    {"params": [...no_decay...], "weight_decay": 0.0},
]
optimizer = torch.optim.AdamW(optim_groups, lr=..., betas=...)

Decay matmul weights, spare the rest. Only nn.Linear weights get weight decay; biases, LayerNorm and Embedding parameters are exempt. AdamW then receives two parameter groups — a careful detail copied straight from how GPT-2 was actually trained.

Part 5

The Trainer

A framework-agnostic loop with an event/callback system

Callbacks & Events

class Trainer:

    def __init__(self, config, model, train_dataset):
        self.callbacks = defaultdict(list)
        ...

    def add_callback(self, onevent: str, callback):
        self.callbacks[onevent].append(callback)

    def set_callback(self, onevent: str, callback):
        self.callbacks[onevent] = [callback]

    def trigger_callbacks(self, onevent: str):
        for callback in self.callbacks.get(onevent, []):
            callback(self)
trainer.add_callback( → 'on_batch_end' → batch_end_callback )

The Trainer knows nothing about your task. Instead of hard-coded logging/eval, it fires named events; you attach callbacks (e.g. print the loss, sample from the model, save a checkpoint) on 'on_batch_end'. This keeps the loop generic and reusable across every demo.

The run() Loop

def run(self):
    model, config = self.model, self.config
    self.optimizer = model.configure_optimizers(config)

    train_loader = DataLoader(
        self.train_dataset,
        sampler=torch.utils.data.RandomSampler(self.train_dataset, replacement=True, num_samples=int(1e10)),
        shuffle=False, pin_memory=True,
        batch_size=config.batch_size,
        num_workers=config.num_workers,
    )

    model.train()
    self.iter_num = 0
    data_iter = iter(train_loader)
    while True:
        batch = next(data_iter)
        batch = [t.to(self.device) for t in batch]
        x, y = batch

        # forward the model
        logits, self.loss = model(x, y)

        # backprop and update the parameters
        model.zero_grad(set_to_none=True)
        self.loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), config.grad_norm_clip)
        self.optimizer.step()

        self.trigger_callbacks('on_batch_end')
        self.iter_num += 1
        # termination conditions
        if config.max_iters is not None and self.iter_num >= config.max_iters:
            break

Device 'auto' picks CUDA when available. An infinite RandomSampler yields endless batches; the loop forwards, back-props, clips gradients to grad_norm_clip, steps AdamW, then fires on_batch_end — stopping at max_iters.

Part 6

minGPT vs nanoGPT

The educational original and its faster successor

Two Decks, Two Goals

minGPT

  • Clean & educational — built to be read
  • Library-structured: model / trainer / bpe
  • Generic Trainer with callbacks
  • CfgNode config + named model zoo
  • Loads GPT-2 weights (weight surgery)
  • Semi-archived Jan 2023

nanoGPT

  • A rewrite "with teeth" — still simple, but fast
  • Single-file model.py + train.py
  • Actually reproduces GPT-2 on OpenWebText
  • torch.compile, DDP, flash attention
  • Mixed precision & gradient accumulation
  • The active, production-leaning successor

In Karpathy's words, nanoGPT shifts focus "from sole education to something that is still simple and hackable but has teeth" — adding industry-benchmark reproduction and runtime efficiency on top of the same core architecture.

Key Takeaways

1

Clarity is a feature. minGPT proves a real, GPT-2-compatible Transformer fits in ~300 readable lines. Every shape is commented; nothing is hidden behind abstraction.

2

Good design separates concerns. A model, a generic callback-driven trainer, a config object and a tokenizer — the same code trains an adder, a sorter, or a language model.

3

The details are the lesson. Scaled residual init, selective weight decay, and Conv1D→Linear weight surgery are exactly the touches that let it load and match real GPT-2 — and that nanoGPT then optimised for speed.
